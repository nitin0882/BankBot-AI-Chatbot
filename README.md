# 💳 BankBot AI – Intelligent Banking Chatbot

An AI-powered chatbot designed to handle banking-related queries efficiently using Natural Language Processing (NLP) and Large Language Models (LLMs). This project aims to improve customer support automation in the banking domain.

---

## 🚀 Features

- 🤖 AI-based chatbot for banking queries  
- 💬 Handles FAQs like balance, loans, cards, accounts  
- 🧠 Smart response generation using LLM (Ollama / NLP models)  
- 🔒 Secure and controlled responses (banking-specific)  
- 📊 Accuracy comparison with other AI chatbot models  
- 🌐 User-friendly interface  

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit / HTML / CSS  
- **Backend:** Python  
- **AI Model:** Ollama / NLP-based chatbot  
- **Database:** JSON / SQLite  
- **Libraries:** pandas, requests, streamlit
